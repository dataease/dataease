# 画布事件订阅清理回归

在主前端目录执行：

```sh
node --test tests/canvas-event-cleanup/regression.cjs
```

测试通过 TypeScript AST 读取实际 `CanvasCore.vue` 的挂载、卸载钩子及清理列表声明，在 Vue 自定义渲染器中挂载、卸载受控组件，使用实际 mitt 事件总线；画布渲染、Store、水印和定时器边界使用桩实现。不启动产品或连接业务后端。

覆盖同一 canvasId 连续 20 次挂载/卸载后监听数恢复基线、重新挂载后一次初始化事件只调用当前实例、不同 canvasId 及同 key 其他订阅互不影响、卸载后的旧事件不再访问旧实例、canvasId 变化后按注册时的 key 清理，以及保留既有快照定时器清理。修改前三个用例均失败，修改后应全部通过。

这不是完整 CanvasCore 渲染、内存压力或编辑/预览/嵌入入口的浏览器回归，也不验证存活实例变更 canvasId 后重新绑定事件。现有画布 DOM、编辑器映射等同样依赖实例身份，本次仅保证注册的监听在卸载时准确释放。

# 轮播提示内容溢出回归（TAPD 1076861）

在 `core/core-frontend` 执行：

```sh
node tests/tooltip-carousel-scroll/check.mjs
```

使用可控时钟验证生产调度函数：短提示保留停留时间、长提示从顶部滚动到底部后才切换、首尾停留、暂停/销毁取消任务、无提示节点时继续轮播。此测试不替代浏览器渲染验证。

产品回归：

1. 大屏添加基础折线图：主维度至少 3 项，子维度至少 5 项，一个主指标及两个动态提示指标，提示字号 14、轮播停留 2 秒，组件高度 330px。
2. 确认长提示从顶部缓慢滚动，最后一个子维度的最后一项指标完整出现并停留后，才切换主维度；提示不超出组件边界。
3. 去掉子维度和动态指标，短提示仍按 2 秒切换，不出现多余滚动。
4. 鼠标进入/离开图表，检查轮播暂停和恢复；悬浮提示应从顶部开始，可手动滚动。
5. 调整组件尺寸、切换 Canvas/SVG、重新打开已保存大屏和预览，确认行为一致且无残留任务。
6. 公共轮播同时用于柱图、面积图、组合图和饼图：回归原有维度切换、图例过滤及暂停行为。

# 连表字段顺序回归

对应 TAPD 缺陷 `1139007144001078003`（V2 报告）：新增右表并勾选字段后，预览将右表字段放到左表前。当前 V3 也存在先遍历子表、再将新增字段前置的逻辑。

```sh
node --test tests/dataset-join-field-order/regression.cjs
```

测试从真实 Vue 组件提取 `dfsFields`、`diffArr`，验证首次连表、已有左表新增右表、多级关联、旧顺序纠正、取消与重新勾选、派生字段保留、自关联同名字段及重复确认。使用构造字段，不访问接口或修改业务数据。

通过 `DATASET_FORM_SOURCE=/path/to/before.vue` 可运行修改前源码对照。

限制：这是字段收集与合并逻辑回归，不覆盖浏览器操作、真实数据库、保存重开或导出。已有数据集的历史字段顺序不会自动迁移，在重新确认关联时按当前表关系重排；派生字段沿用现有保留规则及后续依赖检查。

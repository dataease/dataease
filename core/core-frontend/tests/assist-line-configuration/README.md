# 辅助线配置回归

覆盖单指标分组柱状图、双轴图以及历史辅助线的配置适用性。页面直接挂载生产 `AssistLineEdit.vue`；显隐断言调用生产 `createAssistLineVisibility`，没有复制显隐算法。

## 运行

在 `core/core-frontend` 使用现有依赖启动开发服务，打开 `/tests/assist-line-configuration/index.html`。页面不需要登录，可手动切换用例，操作添加、切换轴、绑定和保存重开，并查看实际发出的配置。

使用 Playwright CLI 自动化时，先在具名会话打开上述页面，然后执行：

```sh
playwright-cli -s=assist-line open http://127.0.0.1:7070/tests/assist-line-configuration/index.html
playwright-cli -s=assist-line run-code --filename tests/assist-line-configuration/browser-check.js
```

可使用已安装的 Codex Playwright wrapper 代替 `playwright-cli`；脚本沿用已打开页面的 origin，不限制开发端口。

## 自动化覆盖

- 单指标分组图：新建固定线默认不绑定、不跟随；控件隐藏；动态计算字段及聚合方式保留；重开后默认值不变。
- 双轴图：唯一指标自动关联、跟随开关可操作、切换所属轴和动态类型、保存回显、多指标选择及跨轴绑定清理。
- 历史配置：已有分组图绑定保留入口；失效绑定不自动转移；历史未绑定配置保持原状，用户主动开启跟随后才关联唯一指标。
- 历史未绑定固定线：保留 `followField: true`、`boundFieldId: ''` 初值；切换动态线后立即显示可操作的跟随开关；关闭、重新开启、反复切换类型和保存重开均保持配置。新建单指标辅助线仍不展示冗余配置。
- 显隐规则：单指标整体参考线、部分/全部分组隐藏、固定/动态线、关闭跟随、图例重置、指标替换，以及普通/分组/堆叠柱线组合图和双折线图左右轴使用相同字段及名称。

通过时返回 `status: PASS`、37 项界面断言和 55 项显隐逻辑断言。这里的“保存重开”是组件卸载再挂载，并非后端持久化验证。

## 完整产品验收

在隔离的本地 DataEase 中建立独立测试数据集、仪表板和大屏，保留其名称、ID、链接及截图，不改动已有业务资源。

1. 数据包含月份、公司、薪资、提成；至少两个分组，两个指标使用不同量级。
2. 分组柱状图使用单指标，新增整体固定参考线和动态平均线，确认没有冗余显隐配置。点击图例隐藏部分分组，参考线继续显示。
3. 普通双轴图左侧薪资、右侧提成，各添加固定及动态线；左右图例分别隐藏和恢复，辅助线按对应轴处理，未开启跟随的参考线保留。
4. 分组/堆叠双轴组合图分别隐藏部分分组和一侧全部分组，确认只有后者隐藏该侧跟随辅助线。再验证两轴同字段、同名指标不串用。
5. 保存资源、刷新并重开，检查新建配置及历史绑定；切换轴、替换指标、关闭跟随和图例重置后重复验证。
6. 验证辅助线超出所属轴范围时隐藏，不能将轴域裁剪误判为跟随失效。检查仪表板/大屏、深浅主题及重复操作。
7. 为单指标分组图准备未绑定、`followField: true` 的历史固定线，打开后切换动态线，确认在同一弹窗即可关闭跟随；保存刷新后验证开关状态及图例显隐行为。

完整产品持久化、实际 G2 渲染、自动刷新及其他入口的验证结果，应单独记录；不能用本页的组件及逻辑断言代替。

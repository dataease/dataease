# 数据集树快速切换回归

在前端目录运行：`node --test tests/dataset-switch/regression.cjs`。

测试提取真实页面的节点选择和预览页签逻辑，使用实际 Lodash debounce 与可控异步响应，覆盖：连续点击仅请求最后一项、取消旧详情/预览/总数请求、乱序返回不覆盖当前资源、旧 finally 不关闭当前加载、页签切换、空字段缓存、预览失败保留详情并允许页签重试及卸载清理；新增切换瞬间清空旧资源 ID/字段/预览/总数、详情失败回到原有未选择状态、旧详情失败不影响最新加载的验证。

这不是浏览器性能基准。AbortController 只保证客户端取消订阅，不保证服务端已开始的查询被终止。150ms 防抖可避免极短连续点击发起无效请求，正常点击仍需等待原有服务端取数。

QA 页面对照需要独立 Playwright CLI 会话登录测试账号；未登录的会话会重定向登录页。本轮没有复用个人 Chrome 凭据或改写 QA 数据，也没有测量修复后的实际页面帧率或耗时。

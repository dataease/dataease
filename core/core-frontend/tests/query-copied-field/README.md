# 查询组件复制字段回归

在 `core/core-frontend` 执行：

```sh
node --test tests/query-copied-field/regression.cjs
```

测试提取生产组件函数，在替换 API 和 Store 边界后执行。覆盖：

- 按图表加载带权限标记的字段，回显 `name_copy`，不向其他图表提供该副本。
- 排除聚合、带参数和系统计数字段，保留脱敏标记与 SQL 参数选项。
- 打开历史自动查询条件时，补齐副本归属并修正跨图表关联。
- 普通字段仍可自动关联同数据集的多个图表，私有副本不跨图表传播。
- 拖入、刷新及保存配置均保留字符串 ID 和副本所属图表；取值字段列表使用同一归属。
- 修改后的查询组件脚本、模板可编译。

测试使用合成字段及图表，不连接真实后端或数据源，不代表完整查询、权限或 SQL 执行回归。

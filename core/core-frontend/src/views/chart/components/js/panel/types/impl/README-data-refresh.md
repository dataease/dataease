# G2 定时刷新适配器扩展说明

定时刷新保留当前图表实例，按数据元素的变化控制动画。手动更新、筛选、钻取、修改样式及添加辅助线仍走原来的完整渲染流程。悬停、图例和提示轮播继续使用原有交互逻辑。

## 刷新链路

`views/index.vue` 的计时器调用 `queryData(false, true)`，将 `autoRefresh` 传入 `ChartComponentG2Plot.vue`。后者执行真实 `getData`，将标识继续传到 `renderChart` 和 `renderG2`。

只有 `autoRefresh && myChart` 时才调用图表的 `updateData`。未适配的图表或组合继续原来的完整渲染，不算增量刷新已支持的范围。首次加载没有实例时正常创建。

`updateData` 的顺序为：检查注册与支持范围 → 比较响应数据 → 匹配新旧数据元素 → 生成本轮主数据和样式 → 暂缓轮播切换 → 同一实例 `options + render` → 更新快照并恢复轮播。数据及响应附加内容完全相同时跳过绘制。

这里使用 `options + render` 是为了分别维护柱子和辅助线的数据，不使用会覆盖所有子图元数据的整图 `changeData`。调用 `render` 不代表销毁实例或全部图元重新入场。

## 动画规则

| 场景 | 基础柱状图行为 |
| --- | --- |
| 原有数值不变 | 保持元素身份，不重新入场；坐标轴或布局变化时允许位置和尺寸过渡 |
| 原有数值改变 | 仅对应柱子从零播放入场动画 |
| 新增维度 | 仅新增柱子播放入场动画 |
| 删除维度 | 对应柱子直接移除，其余不重新入场 |
| 维度重排 | 保持身份并调整位置 |
| 全部数据变化 | 全部柱子播放入场动画，但不销毁实例 |
| 数据变空再恢复 | 保留实例，显示空状态；恢复的元素正常入场 |

折线保留系列身份，整条路径使用更新过渡；改值和新增的数据点使用点图元的入场动画，不因一个点变化而整条线重新入场。

身份由维度、系列和指标 ID 分组，并分配实例内编号。重复维度优先匹配数值未变的行，再匹配改值行。输入没有独立业务 ID 时，完全相同的重复行无法区分业务身份，但仍保留可匹配的未变元素。数值参与最终图元 key，使改值进入入场分支；行索引不参与身份，因此删除和重排不会让后续全部元素重新入场。内部 key 只写入渲染数据副本，不修改后端响应或真实数据源。

## 当前支持范围

| 图表或功能 | 状态 |
| --- | --- |
| 基础柱状图，单指标 | 已注册 |
| 基础折线图，单指标 | 已注册 |
| 普通标签和最值 | 复用既有数据转换与标签回调，保留旧 HTML 清理 |
| 固定和动态辅助线 | 已适配，使用独立数据 |
| 柱状图条件颜色 | 已适配，每轮重新计算新值的颜色 |
| 折线条件分段 | 待适配，保留完整渲染 |
| 提示轮播 | 保留进度与暂停状态，已适配柱状图跨刷新保留轮播背景并同步位置和宽度 |
| 缩略轴、平铺图例 | 待适配，保留完整渲染 |
| 多指标、子维度、堆叠维度、非有限数值 | 暂不支持增量刷新 |
| 超过公共大数据工作量阈值、未知附加图元 | 保留完整渲染 |

例如条件为“大于 50 显示红色”，A 保持 30、B 从 40 变成 60 时，条件适配器先把 B 计算为红色，再由图表适配器让 B 入场，A 不重新入场。B 回到 40 时恢复正常颜色。

## 图表注册

核心接口位于同目录的 `g2-data-refresh.ts`，执行调度位于 `g2.ts`。图表类在构造函数中显式注册，不能让子类自动继承适配资格。

基础柱状图的实际接入位于 `../../charts/g2/bar/bar.ts`：

```ts
if (name === 'bar') {
  registerChartRefreshAdapter(name, {
    valueChannel: 'y',
    marks: [{ type: 'interval', key: 'item' }],
    assistLines: (chart, options) => this.getAssistLineStyle(chart, options),
    conditions: (chart, options) => this.configBarConditions(chart, options)
  })
}
```

`valueChannel` 声明数值轴，防止数据变空时被推断为分类轴。`marks` 对应 Spec 开头的主图元顺序。柱子和点使用 `item`，整条线使用 `series`。首次最终 Spec 装配完成后、首次 render 前，调用 `configureDataRefresh(instance, chart, options)` 登记身份。基础折线的示例位于 `../../charts/g2/line/line.ts`。

接入新的图表时先验证其数据模型符合身份规则；不能只登记名称就认为已经支持。`getRefreshUnsupportedReason` 返回图表未注册、多系列、非有限数据或不兼容样式的标识，供测试和排查使用。

## 样式适配器注册

`g2-data-refresh.ts` 的 `styleRefreshAdapters` 集中维护样式支持能力。每个条目提供：

- `enabled(chart)`：当前是否启用该功能
- `supports(adapter, chart)`：当前图表是否能更新它；待适配功能显式返回 false
- `update(options, chart, adapter)`：可选，在本轮 render 前生成最新样式
- `markId`：可选，拥有独立附加图元时声明归属

新增附加图元需要通过 `tagRefreshComponentMarks(markId, marks)` 标记，并放在主图元之后。更新方法只生成本组件的内容，保留主图元的 key 和编码。组件每轮收到最新数据，不依赖旧响应闭包。

条件样式适配器调用图表已有的条件计算，避免维护第二套颜色规则。它每轮从新的主数据建立转换，不叠加上一轮的数据转换。辅助线适配器调用图表已有的辅助线生成逻辑，不把主数据覆盖到辅助线。

已适配柱状图的轮播背景由轮播实例接管，解除 G2 原生交互对该节点的所有权，避免 render 重建交互时将其移除。绘制完成后沿用原生高亮计算的新几何，同步至保留节点，不增加轮询或逐帧跟随计时器。轮播切换仍沿用现有调度，空数据、停止轮播或进入鼠标悬浮时释放背景；未适配图表仍由原生交互管理背景。

标签和轮播不需要额外生成图元配置：标签随主数据转换计算；轮播在公共执行入口暂停、恢复，并读取最新数据。静态字体、边框等不依赖数据的样式无需单独登记。

有事件或外部状态的新增组件还需接入 `prepareOptions` 和卸载清理，参考 `ChartComponentG2Plot.vue` 中辅助线图例显隐适配器的解绑与安装。声明一个名字不会自动处理生命周期。

## 保留和清理的内容

保留静默 loading、请求锁、预览刷新入口、唯一计时器、渲染串行化、最值清理及轮播进度协调。

移除旧的 `G2DataRefreshConfig`、`G2RefreshComponent`、配置路径白名单、手动配置局部更新比较、只允许末尾追加的判断，以及轮播背景克隆和逐帧跟随逻辑。手动样式修改不再尝试增量更新。

## 开发测试

开发环境保留真实 `getData` 成功回调中的响应模拟，文件为 `views/chart/components/views/components/chart-refresh-mock.ts`，不写真实数据源。

`sessionStorage` 中的 `de-chart-refresh-mock` 可设置为 `mixed`、`append`、`change` 或 `off`。默认关闭，显式选择 `mixed` 后每轮追加一个维度，并轮流只修改一个原有维度的数值，其他已有维度保持上一轮的值。最多追加 20 个维度，之后继续单独修改数值；轮流增大、恢复数值，便于观察局部入场效果。手动查询、后端数据变化或切换模拟模式时重置模拟结果。

仅开发环境可在浏览器控制台显式开启或关闭模拟，刷新页面后生效：

```js
sessionStorage.setItem('de-chart-refresh-mock', 'mixed')
// 测试完成后关闭
sessionStorage.removeItem('de-chart-refresh-mock')
```

实例通过首次配置校验后才登记局部更新能力。轮播背景节点保留、最值旧节点清理、辅助线图例状态延续依据实例能力启用，不向未适配图表扩散。未适配的分组柱、堆叠柱、面积图、饼图等保持完整绘制路径。

刷新计时器、预览入口补齐、定时刷新静默 loading、G2 渲染串行化及卸载保护仍属于公共改动，不应描述成“其他图表完全没有改动”。串行化用于避免异步绘制与下一次刷新、卸载交错操作同一实例；公共入口仍须回归验证。

在 `core/core-frontend` 下运行：

```sh
node tests/chart-data-refresh/check.mjs
node tests/tooltip-carousel-scroll/check.mjs
```

第一项覆盖注册边界、局部变化、重复维度、删除重排、空数据恢复、样式数据隔离、测试数据逐轮局部变化、计时器生命周期及未适配柱形图的背景行为。第二项覆盖已有轮播调度。浏览器回归需要使用实际图表类，检查 Canvas、SVG 的入场动画作用于哪些元素，不能只判断画布实例是否保留。

全量类型检查为 `npm run ts:check`；当前已有生成的 `.vue.js` 文件会触发 TS6504，不通过修改 `allowJs` 掩盖。

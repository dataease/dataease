# 电子表格 Excel 导入

在资源树顶部或文件夹的「+」菜单选择「导入 Excel」，可以在对应目录新建电子表格。在编辑器中选择「导入 Excel」，选中的工作表会追加到当前电子表格。两个入口都支持 `.xlsx`。

默认选中可见工作表。勾选「显示隐藏工作表」后可以选择隐藏页，选中的隐藏页会作为可见工作表导入。确认页支持逐表改名，同批导入的明确跨表引用会随名称更新。确认后打开首张导入页，使用编辑器的保存和发布操作分别更新草稿和发布版本。编辑器中的整批追加可以一次撤销。

## 公式处理

| 模式                 | 导入规则                                                                                                                                 |
| -------------------- | ---------------------------------------------------------------------------------------------------------------------------------------- |
| 保留兼容公式（默认） | 可安全迁移的普通算术、引用和 Univer 已实现函数保留为公式。其余公式有可用缓存时列出位置和原因，经确认后转值。缺少可用缓存则阻止整批导入。 |
| 保留所有公式         | 可安全迁移的普通公式保留原文，未知函数也可以在编辑器继续修改。漏选依赖工作表、外部引用或无法完整迁移的数组等情况会列出位置并阻止导入。   |
| 仅导入计算结果       | 逐格写入 Excel 保存的可用缓存结果。遇到缺少缓存的位置会阻止整批导入。                                                                    |

三个模式的预览都显示 Excel 保存的缓存，`0` 和 `FALSE` 均为有效结果。即使预览显示「缺少缓存结果」，符合所选保留策略的公式仍可导入并在编辑器重算。

## 容量与格式

单个文件上限为 20 MB，每张表最多 10,000 行。整簿按每张表的已用行数乘以已用列数累加，上限为 200,000 格，含未勾选的工作表。每张表最多预览 100 行、30 列。相关阈值集中在同目录 `protocol.ts` 的 `IMPORT_LIMITS` 中。

可选择导入数据和基础格式，或仅导入数据。基础格式包括字体、颜色、数字格式、行高、列宽和合并单元格。

## 由仪表板传入筛选值

例如「根据账户查询用户信息」要求按账户筛选，具体账户由使用者传入。将已核对的列放在比较符左侧，右侧使用作者指定的参数名。需要自行命名时取独立名称，如 account。新建筛选条件时，将完整条件写在一个单行块内。

```sql
SELECT u.account FROM users u
WHERE $DE_PARAM{u.account = $[account]}
```

各个可选条件分块书写，按作者要求在块之间使用 AND 或 OR。块缺少输入时，整块条件为真。若此块以 OR 连接，即使另一条件不成立，整组也为真。作者可在「参数设置」配置类型和默认值，预览采用适用的默认值，仪表板运行时传入筛选值。

作者给定固定筛选值时，直接用字段与该值比较。作者指定参数的预览默认值时，保留占位符并说明如何在「参数设置」填写。作者只要求「查询所有用户」时，直接返回用户列表。

## 修改已有参数

从 sqlBasis 沿用相关参数名，以便复用已有配置。若草稿已经用旧式仪表板参数，新增参数也沿用该写法，系统变量直接放在比较条件里。

```sql
SELECT u.account FROM users u
WHERE u.account = ${account}
```

## 使用当前身份或自定义系统变量

例如「查询当前登录账户的信息」，用实际存储登录账号的列与账号系统变量比较。如果 systemVariableNames 含有显示名「账号」，可写为

```sql
SELECT u.account FROM users u
WHERE $DE_PARAM{u.account = $f2cde[账号]}
```

其他系统变量也使用 systemVariableNames 中的准确显示名。找不到对应项时，请作者确认编辑器中显示的名称。编辑器负责将显示名映射为运行标识，变量值由 DataEase 在运行时解析。

# 错误契约与兼容迁移

对应 TAPD 1140899682001022855。正常成功响应仍为既有 `code/msg/data`，错误继续使用 `ResultMessage`，不引入第二套响应包装。

## 协商与兼容

主前端请求声明 `X-DE-Error-Contract: 2`。没有该声明的 AK/SK、旧 SDK、分享及嵌入消费者保留既有错误状态和响应字段；这不是鉴权标识，不能用于放行请求。新的服务端兼容旧前端，新的前端同时兼容旧的错误响应。

契约 2 的错误可包含 `category`、`messageKey`、安全的 `args`、`requestId`、`fieldErrors` 和 `retryable`。`msg` 是服务端按语言生成的用户消息，不再增加平行的 `message` 字段。未提供的错误元数据省略，成功响应不增加错误字段。字段错误不返回 rejectedValue。`data` 只允许业务显式提供的安全详情，例如保存冲突的当前内容版本标识，不返回资源内容。

每个请求使用 `X-DE-Request-ID` 关联响应和日志；仅接受 32 位十六进制标识，否则服务端重新生成。Servlet MDC 在请求结束时恢复，异步及错误分派复用同一标识。认证子请求需透传契约标识、语言和请求 ID，认证成功响应的请求 ID 继续透传给业务上游。跨域响应暴露这些必要头。

## 分类与码表

显式 `DEException.category` 优先；只对已核查、含义明确的公共码使用登记映射。默认 40001 承载的历史业务校验不能按中文文案或数字区间推断。

| 类别             | HTTP | 新异常默认业务码 | 历史码兼容说明                                                             |
| ---------------- | ---- | ---------------- | -------------------------------------------------------------------------- |
| VALIDATION       | 400  | 10001            | 明确参数码 10001—10004；迁移的旧参数校验可保留 40001 并显式指定类别        |
| UNAUTHENTICATED  | 401  | 20001            | 登录失败 20002 不等同于会话失效，不能自动清缓存跳登录                      |
| FORBIDDEN        | 403  | 70001            | 账号禁用 20003、明确权限不足 70001；网关权限标志仍保留                     |
| NOT_FOUND        | 404  | 70002            | 用户不存在 20004、数据不存在 50001、资源不存在 70002；先保持原有鉴权       |
| CONFLICT         | 409  | 50005            | 重复 20005/50003、版本冲突 50005、配额 80001；不再将明确配额错误当登录失效 |
| UPSTREAM         | 502  | 60002            | 不把远端 HTTP404 当本地资源不存在，不将本地磁盘错误当外部故障              |
| UPSTREAM_TIMEOUT | 504  | 60005            | 与客户端 Axios 超时及正常取消分别处理                                      |
| INTERNAL         | 500  | 40001            | 未知异常和非认证 NPE 返回稳定消息，原始原因仅保留在日志                    |

协议错误保留 413、404、405、406、415 等状态与必要响应头。50002 图表局部详情、50004 资源引用约束、60003 扩展静默分支和旧响应 80001 的会话恢复语义逐项保留，不能机械批量转换。60001 内部调用、60004 接口地址无效、60006 负载过高、字面码 403/50000 仍走历史兼容路径，待业务入口明确分类后迁移。重复定义的 50004 本次不重编号。

网关透传字段依据 [APISIX 3.19 forward-auth 官方文档](https://apisix.apache.org/docs/apisix/plugins/forward-auth/)核对；另通过本地前端 → 实际 APISIX 3.17 → 本地后端执行链路回归，验证认证失败状态、错误类别和请求关联头。安装配置版本与运行版本需分别核实。

## 前端消费

`DataEaseError`保留 `httpStatus/code/requestId/fieldErrors/category/messageKey/retryable`、原始 Axios 错误 `cause`、`response/config`。`code`是业务码；没有业务码时保留传输错误码，`transportCode`始终表示 Axios 码。需要兼容旧 Axios 输入的调用方使用 `isRequestError`，不能依赖 `isAxiosError`识别包装后的业务错误。

续期标志与等待队列均保留在各标签页内，同页请求合并续期，避免共享存储标志使其他标签页的独立队列永久等待。

统一呈现器记录错误的 `presented`状态；局部 catch 使用同一呈现器避免重复提示。`handleErrorLocally`在 HTTP 和业务失败两条路径都生效。正常取消保留取消对象，不弹窗。失败不能变成成功或空结果。`retryable`只表达类别，不自动重放保存、发送等有副作用的请求。

认证恢复优先使用网关稳定原因标识，保留旧响应头适配；HMAC 专用码、challenge 及旧插件消息兼容集中在 HMAC 适配器。RSA 公钥变化提供稳定 messageKey，旧服务端字符串识别仅作为兼容回退。文件下载的正常 Blob 保持原形态，JSON 错误 Blob 拒绝，已提交的文件流不追加 JSON。

## 本次业务试点与边界

- 远程 CSV/XLS/XLSX 加载：解码和参数校验、下载边界、明确格式错误、网络失败/超时和未知故障分别分类；保留下载预算、临时文件清理与成功预览。不能按所有 IOException 或所有解析异常分类。
- 编辑保存：新编辑器携带 `checkHistory/expectedContentId`；保存事务内锁定主记录、比对版本后才写主表、镜像及图表。冲突返回 50005 和当前版本，前端明确确认后再对该版本重试；取消或失败不重置输入与保存缓存。旧客户端不强制版本校验，但保存同样经过行锁，与新客户端串行。新版前端按预检查响应上的能力标识判断服务端版本；旧后端仍执行原来的预检查/覆盖确认，新后端由保存接口完成冲突确认。能力关联到具体响应，不能用全局状态混淆并发请求。
- 保留已解决的角色不存在、报告创建和阈值缺参校验，并为明确的失败补充类别。未批量改写所有历史 40001、所有图表原始详情或其他业务模块；不能据此宣称全仓迁移完成。

## 登录与多类型权限拒绝

新契约下，错误密码和账号不存在属于 VALIDATION / HTTP400，不能当作已有会话失效清缓存；账号禁用或锁定属于 FORBIDDEN / HTTP403。登录接口不附加网关权限拒绝头，保持登录页单次错误提示。原有锁定计数、剩余次数及文案保留；旧契约仍按原有业务码和 HTTP 状态消费，不批量重编号历史 40001。

多资源类型权限检查保留任一类型允许即可通过的行为。全部拒绝时，明确的权限不足不能被另一个类型下的资源不存在覆盖；全部类型均不存在时仍返回 NOT_FOUND。意外故障不伪装成资源不存在。登录/权限实链 17 项、新旧登录响应和真实页面提示均已验证通过；类型组合、错误优先级及计数另由隔离断言验证。

本地产品链路另验证了真实编辑器保存重开、冲突取消/确认、匿名分享启用/停用、移动预览，以及失效用户/嵌入/分享身份。有效嵌入应用的跨域 DIV 加载、销毁重建及 Token 失败/撤销已补充实测；经授权补充本机前端自身来源并重启后，跨域 iframe 的握手、认证和资源加载也已实测通过，完整嵌入回归 9/9 通过。已补充受限用户的自定义角色读取/管理/撤销及跨组织资源拒绝、真实 LDAP 登录与失败路径、多标签页续期和完整服务端会话到期。已通过现有 MySQL 直连数据源补测真实聚合、计算字段、筛选排序、用户/角色行列规则及实际 XLSX 导出的过滤和脱敏；分析引擎未配置，Excel/API 导入、跨源查询和全部图表类型仍未覆盖；真实 SMB/外部数据源、其他数据库和部署 Profile 未覆盖。主应用开发入口通过不等于生产打包或全部入口验收；TAPD 关闭需据实际覆盖判断。

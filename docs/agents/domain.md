# Domain docs

适用范围遵循根目录 `AGENTS.md` 的 Agent skills 节。

采用 single-context 布局：

- 根目录 `GLOSSARY.md`：共享业务术语。
- 根目录 `docs/adr/`：架构决策记录。

## 阅读规则

探索代码前，读取已有的 `GLOSSARY.md` 和与当前任务相关的 ADR。
若以后存在 `GLOSSARY-MAP.md`，按其索引读取相关上下文文档。

文档不存在时继续工作，无需报告缺失或预先创建空文件。
在术语或决策实际明确后，由 domain-modeling 工作流按需补充。

## 使用规则

Issue、方案、测试和代码命名沿用术语表定义。
发现术语缺口时，先确认项目已有用语，再记录需要补充的概念。
方案与已有 ADR 冲突时，指出具体记录、冲突内容和重新评估理由。

XPack 内部领域文档保留在其独立仓库；
主仓库仅记录必要的公共契约和兼容性说明。

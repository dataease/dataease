# Triage labels

适用范围遵循根目录 `AGENTS.md` 的 Agent skills 节。

| 技能角色 | GitHub 标签 | 含义 |
| --- | --- | --- |
| needs-triage | needs-triage | 等待维护者评估 |
| needs-info | needs-info | 等待补充信息 |
| ready-for-agent | ready-for-agent | 规格明确，可由代理自主实施 |
| ready-for-human | ready-for-human | 需要人工实施 |
| wontfix | wontfix | 不予实施 |

技能引用分诊角色时，使用上表对应标签。
这些标签与仓库已有的类型、优先级和状态标签并存；
保留已有标签，避免将不同含义的分类自动互相替换。

# 辅助线回归

在仓库根目录执行（需已有前端依赖）：

```bash
node tests/assist-line/verify.mjs
node tests/assist-line/verify-mix-domain.mjs
```

`verify.mjs` 检查指标绑定、别名、子维度和左右轴的显隐映射。
`verify-mix-domain.mjs` 直接执行生产代码中的组合图比例尺同步逻辑，覆盖：

- 关闭跟随、历史配置缺少跟随字段，以及固定线未绑定指标时，图例筛选保留初始轴域。
- 仅有跟随线的轴继续使用筛选后的范围，左右轴互不影响，同轴散点与主图范围一致。
- 动态响应缺少跟随字段时使用持久化配置判断；新一轮数据绘制重新确定初始轴域。
- 保持原有手动范围、初始越界线、负值、非有限值和缺少源比例尺的处理。

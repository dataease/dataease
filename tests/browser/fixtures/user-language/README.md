# 用户语言解析回归

从仓库根目录执行：

```sh
npm --prefix tests/browser test -- --config=user-language.config.mjs
```

隔离 Vite 页面监听 `127.0.0.1:4193`，复用主前端现有依赖，不安装依赖、不连接业务后端或数据库。

测试加载真实语言解析工具、缓存、Pinia Store、国际化初始化和切换代码，仅替换用户信息、支持语言列表及自定义语言包接口。浏览器偏好和缓存按用例设置，通过真实页面刷新核对最终语言、缓存、请求使用的语言、HTML 语言和刷新次数。覆盖用户设置优先、缓存回退、浏览器偏好顺序、中文脚本与地区、失效自定义语言、语言包加载失败，以及嵌入模式。

这是语言链路的浏览器回归，不等于完整产品登录、移动端或嵌入宿主验收。

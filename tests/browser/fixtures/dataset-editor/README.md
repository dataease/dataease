运行：`npm --prefix tests/browser test -- --config=playwright.dataset-editor.config.cjs`。

夹具加载真实的数据集编辑入口、关联画布、节点详情、字段选择和菜单组件、Vue、Element Plus 以及主应用全局样式。替换 API、路由、Store、国际化初始化、图标和非本次目标的编辑器弹框边界；所有数据均为合成数据，不连接业务后端，不保存真实数据集。

覆盖首次拖表、节点/步骤切换、字段勾选即时写回、字段 ID 同步、保存与离开提示、批量管理、单节点预览、乱序响应、失败重试、未 drop 前拖拽不重复请求，以及节点菜单的字段选择、SQL 重命名/编辑入口和依赖删除确认。取消依赖删除会恢复原勾选；字段搜索与筛选全选不会清空搜索词或改变未筛选字段。底部不再显示取消/确认按钮。

普通表和 SQL 节点预览均按独立根节点序列化，只携带自身字段，清空父子关联并保留 SQL 参数；进入数据处理后，原关联树与计算字段保持完整。SQL 编辑器使用仅展示入参的桩组件，不执行真实 SQL，也不验证 SQL 编辑保存过程。

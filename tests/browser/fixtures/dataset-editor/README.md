# 数据集编辑步骤回归

运行：`npm --prefix tests/browser test -- --config=playwright.dataset-editor.config.cjs`。

夹具加载真实的数据集编辑入口、关联画布、节点详情、字段选择和菜单组件、Vue、Element Plus 以及主应用全局样式。替换 API、路由、Store、国际化初始化、图标和非本次目标的编辑器弹框边界；所有数据均为合成数据，不连接业务后端，不保存真实数据集。

覆盖首次拖表、节点/步骤切换、字段勾选即时写回、字段 ID 同步、保存与离开提示（未做任何修改时退出不再提示）、批量管理、单节点预览、乱序响应、失败重试、未 drop 前拖拽不重复请求，以及节点菜单的字段选择、SQL 重命名/编辑入口和依赖删除确认。取消依赖删除会恢复原勾选；字段搜索与筛选全选不会清空搜索词或改变未筛选字段。底部不再显示取消/确认按钮。

普通表和 SQL 节点预览均按独立根节点序列化，只携带自身字段，清空父子关联并保留 SQL 参数；进入数据处理后，原关联树与计算字段保持完整。SQL 编辑器使用展示入参并可发出合成保存/关闭事件的桩组件，不执行真实 SQL。回归通过可控 Promise 分别释放关闭抽屉与节点详情的字段请求，覆盖两种响应顺序、期间修改字段及删除节点；检查无页面异常、勾选状态、保存字段与 ID 一致性。单节点字段接口失败后，使用原有刷新按钮重试并确认保存元数据未丢失。

拖拽修复前，12 轮 dragover/dragleave 使字段请求由 1 次增加至 13 次；独立节点预览修复前，currentDs 多带 currentDsFields、unionType、unionFields，相关断言均失败。

截图输出到忽略的 output 目录。未覆盖真实数据库方言、SQL 执行、创建数据集弹框和生产构建。

区域全屏覆盖画布/详情独立展开与恢复、节点/搜索/预览状态保留、窗口缩放后尺寸及步骤切换重置。详情全屏时，SQL 节点重命名和 SQL 编辑弹窗仍须可见；修复前重命名弹窗被隐藏画布容器遮住，回归在可见性断言失败。

字段选择表对齐原型的五个数据列：物理字段名、数据集字段名、数据集字段类型、来源物理表、备注。名称和类型沿用现有数据集字段配置及类型转换逻辑，物理字段保留原始信息。覆盖行内编辑到单节点预览、保存、模拟接口重新读取的完整链路，以及未勾选字段的配置在切换节点后保留、勾选时应用。夹具通过 JSON 克隆隔离节点物理字段和 allFields，避免与真实 HTTP 响应不同的对象引用共享。

补充覆盖：SQL 响应在依赖删除确认框等待期间返回，分别确认/取消后检查勾选、计算字段与保存字段 ID；再次打开 SQL 编辑器且不修改直接关闭，不应丢弃前一次有效刷新。前一版这三个用例均失败，修复后需与原有用例一起通过。

编辑已有数据集默认进入数据处理，新建仍进入表关联。原有节点用例通过顶部入口返回关联页后继续验证；新增覆盖居中的顶部图标工具栏、修改字段后往返与保存重开，以及左侧源表详情的只读预览、字段搜索、独立字段 ID、关闭重开后的字段/预览乱序响应、请求失败后刷新重试和源表拖入画布。表详情取数不带画布中的其他节点，也不改变画布字段选择。

批量管理把计算字段与其依赖字段一起改为 URL 后应能改回原类型。`dependency=1` 附带计算字段，`calcAbsent=1` 让计算字段不带 `deExtractType`、`calcNull=1` 将其置为 `null`，模拟新建未保存与历史数据两种缺失形态。修复前批量类型选择器在改类型后变为禁用，回归在改回时的可编辑断言失败。
